# PLAN-004: Store core (for T-004)

- **Task:** [T-004](../tasks/T-004-store-core.md)
- **Status:** Executed
- **Date:** 2026-11-04

## Approach
Implement ADR-005 with SQLAlchemy 2 + Alembic ([ADR-015](../decisions/ADR-015-db-access-sqlalchemy-alembic.md)). Create every HLD §7 table now: later tasks extend them through migrations instead of inventing tables, and the ER diagram stays true. Repositories expose a small API that returns DTOs.

## Steps
1. Settings: `data_dir`, `artifacts_dir`, `database_url`.
2. `models.py` (14 tables), `db.py` (`Database`, sessions, SQLite pragmas, `migrate()`), `immutability.py`.
3. Alembic env + initial migration (autogenerated) + immutability triggers.
4. Repositories: `ProjectRepository` (projects, pages, origin rule), `SnapshotRepository`, `ArtifactStore` (create/new_version/get/latest/history/diff/restore), `ArtifactFiles`.
5. `migrate.py` CLI + `poe db-upgrade` / `poe db-revision`.
6. Tests (TC-104), docs.
