## Approach
Build a runnable, empty system that every later task plugs into. The tooling choices came from the S002 interview and are recorded in [ADR-012](../decisions/ADR-012-backend-and-dev-tooling.md) (backend and dev tooling) and [ADR-013](../decisions/ADR-013-frontend-libraries.md) (frontend libraries).

- **Python:** one `pyproject.toml` at the repo root, so every command runs from the root. It defines a single package `gatp` in `backend/src/gatp/` with one sub-package per module. Python 3.12 is managed by uv and locked in `uv.lock`.
- **Two entrypoints:** `gatp-api` (uvicorn + FastAPI) and `gatp-runner` (a stub that idles; T-006 chooses the job protocol).
- **Tasks:** poethepoet tasks declared in `pyproject.toml` (`uv run poe <task>`), so they work the same on Windows, macOS and Linux. Frontend tasks shell out to `npm --prefix frontend`.
- **Frontend:** `frontend/` holds a Vite + React + TS app using Mantine and TanStack Query. It calls the API through a client generated by `openapi-typescript` and called through `openapi-fetch`.
- **OpenAPI schema:** exported by a Python script (`gatp.api.export_openapi`) to `frontend/openapi.json`, so no running server is needed. CI regenerates the schema and fails if the committed files differ.
- **Dependency direction:** enforced with import-linter contracts that mirror [modules/README](../modules/README.md#dependency-direction).

## Steps
1. Write ADR-012 and ADR-013.
2. Root `pyproject.toml` with dependencies, dev group, ruff, mypy (strict), pytest, import-linter and poe tasks; `.python-version` = 3.12; `uv lock`.
3. `backend/src/gatp/`: `config.py` (pydantic-settings), `api/app.py` (factory + `/api/health`), `api/__main__`/`main()` entrypoint, `api/export_openapi.py`, `runner/main.py` stub, empty packages for the other modules.
4. `backend/tests/`: health endpoint, OpenAPI export, runner stub, import contracts.
5. `frontend/`: Vite React TS app, ESLint (flat config) + Prettier, Mantine, TanStack Query, `src/api/schema.d.ts` (generated) + `src/api/client.ts`, `HealthBadge` component, Vite proxy `/api → http://127.0.0.1:8000`.
6. `.env.example` (`GATP_` keys) and `.gitignore` updates.
7. `.github/workflows/ci.yml` with a backend job and a frontend job on ubuntu-latest.
8. Docs: SG-001 (setup and run), SG-002 (developer workflow), module LLD `Code:` paths, api/runner/web-ui LLD sections, README layout, task doc + Explain it, TC-102 status, session log S002.
